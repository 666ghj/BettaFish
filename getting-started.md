# Getting Started with BettaFish

Welcome to BettaFish! This guide will help you set up and start using the project.

## Prerequisites

- Python 3.8 or higher
- pip package manager

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/imah-domo172/BettaFish.git
   cd BettaFish
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the main application:
```bash
python main.py
```
