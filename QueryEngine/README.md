## 概述

**QueryEngine** 是 BettaFish（微舆）多智能体舆情分析系统中的核心组件之一，专门负责**精准信息搜索**。它通过整合 Tavily 新闻搜索 API 和大型语言模型（LLM），实现对国内外新闻的智能搜索、深度分析和报告生成。

### 主要特点

- 🔍 **多工具搜索能力**：支持 6 种专业新闻搜索工具（基础搜索、深度分析、24小时新闻、本周新闻、图片搜索、日期范围搜索）
- 🤖 **AI 驱动决策**：使用 LLM 智能选择搜索工具和生成搜索查询
- 🔄 **反思机制**：通过多轮反思循环，不断优化和完善搜索结果
- 📊 **结构化输出**：生成结构化的深度研究报告
- 🔗 **论坛协作**：支持与 ForumEngine 集成，读取论坛主持人发言进行协作

## 核心功能

1. **报告结构生成**：根据用户查询，自动规划报告的结构和段落
2. **智能搜索**：为每个段落生成最优搜索查询并选择合适的搜索工具
3. **深度总结**：基于搜索结果生成信息密集的分析段落（800-1200字）
4. **反思优化**：通过多轮反思循环，补充遗漏信息，完善分析内容
5. **报告格式化**：将研究结果格式化为专业的 Markdown 报告

## 代码阅读顺序推荐

如果你想深入理解 QueryEngine 的代码实现，建议按照以下顺序阅读，从基础到高级，逐步理解整个系统：

### 📚 第一阶段：基础模块（理解数据结构和配置）

**1. `utils/config.py`** - 配置管理
- 了解系统的配置项和参数
- 理解如何使用 pydantic-settings 管理配置
- **阅读时间**：5-10 分钟

**2. `state/state.py`** - 状态管理
- 理解整个系统的数据模型（State → Paragraph → Research → Search）
- 了解状态如何序列化和持久化
- **阅读时间**：15-20 分钟
- **关键点**：注意数据结构的层次关系和状态流转

**3. `utils/text_processing.py`** - 文本处理工具
- 了解 JSON 解析、清理、修复等工具函数
- 这些函数被节点广泛使用，理解它们有助于理解后续代码
- **阅读时间**：10-15 分钟

### 🔧 第二阶段：核心工具（理解外部接口）

**4. `tools/search.py`** - 搜索工具集
- 理解 6 种搜索工具的实现和区别
- 了解 Tavily API 的封装方式
- **阅读时间**：20-25 分钟
- **关键点**：注意每种工具的适用场景和参数要求

**5. `llms/base.py`** - LLM 客户端
- 理解如何封装 OpenAI 兼容的 API
- 了解流式输出、重试机制、时间戳注入等特性
- **阅读时间**：15-20 分钟
- **关键点**：注意 `stream_invoke_to_string` 方法如何安全处理 UTF-8 字符

### 🏗️ 第三阶段：节点架构（理解处理流程）

**6. `nodes/base_node.py`** - 节点基类
- 理解节点的抽象接口和设计模式
- 了解 `BaseNode` 和 `StateMutationNode` 的区别
- **阅读时间**：10 分钟
- **关键点**：这是所有节点的基类，理解它有助于理解后续节点

**7. `prompts/prompts.py`** - 提示词模板
- 快速浏览各个阶段的提示词
- 理解 LLM 的输入输出格式要求
- **阅读时间**：15-20 分钟

**9. `nodes/search_node.py`** - 搜索查询生成

**11. `nodes/formatting_node.py`** - 报告格式化

- **这是最重要的文件**，整合了所有模块

- **关键点**：
  - 注意整个工作流的协调逻辑

**13. `__init__.py`** - 模块导出
- 了解模块的公共接口
- **阅读时间**：2 分钟
